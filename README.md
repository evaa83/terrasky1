# 天之校｜中橫田野影像行動

2027 天之校一頁式活動網站，使用純 HTML 與 CSS，無需安裝依賴或建置。

## 網站檔案

- `dist/index.html`：網頁文案、樣式與頁內導覽。
- `dist/assets/`：網站使用的場域及歷次活動照片。

## 本機預覽

```sh
python3 -m http.server 8000 --directory dist
```

開啟 http://localhost:8000/ 。修改 `dist/index.html` 後重新整理即可。

## 部署

可將 `dist/` 作為靜態網站發布目錄。本儲存庫保存網站原始檔與照片；上傳 GitHub 不會自動更新既有 Sites 網址，也尚未啟用 GitHub Pages。
